# amadrazo-portfolio

Personal portfolio website of Alejandro Madrazo.

## Stack

Planned: [Next.js](https://nextjs.org/) + [Tailwind CSS](https://tailwindcss.com/).

## Getting started

```bash
# scaffold (when ready)
npx create-next-app@latest .

# run the dev server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
